# Protocolo de entrada (IA)

1. Si el trabajo es **sobre el kit/manual**: lee [`../AGENTES.md`](../AGENTES.md).
2. Si el trabajo es **dentro de un proyecto ya sembrado**: lee el `AGENTES.md` **de ese proyecto** (junto a `docs/`), no reescribas el pack.
3. No leas la memoria `95-memoria/`.
4. Herramientas autorizadas: solo fichas `35-herramientas/autorizadas/` con status authorized cuando el humano lo pide en alcance.
