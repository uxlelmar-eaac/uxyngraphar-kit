# CLAUDE.md — repositorio del kit uxyngraphar

Este repositorio es el **kit** (el motor y el catálogo de sistemas), no un proyecto con sistemas instalados. Antes de cambiar nada:

1. Lee [`español/AGENTES.md`](español/AGENTES.md): qué se puede tocar y cómo cerrar un cambio.
2. Para crear o cambiar un sistema, sigue [`español/motor/GUIA-PARA-AGENTES.md`](español/motor/GUIA-PARA-AGENTES.md): siempre con el generador, nunca copiando a mano.
3. Para contribuir al motor, [`CONTRIBUTING.md`](CONTRIBUTING.md) y las decisiones de [`decisiones/`](decisiones/README.md).
