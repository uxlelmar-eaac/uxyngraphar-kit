# Glosario (cliente)

| Término | Significado |
|---------|-------------|
| Reception | Capa que adapta JSON del API a la vista |
| Funcionalidad / módulo | Dominio bajo la carpeta de features/módulos del proyecto |
| Instrucción | Orden humana; contrato `lectura_minima` + anclas |
| Lectura mínima | Paths docs permitidos para la IA en una tarea |
| Presupuesto | Límite default 8 docs / 5 archivos código |
| Área | Pack `25-areas/<id>/CONTEXTO.md` |
| Endpoint servidor | Ruta del API servidor; citar desde CONTEXTO, no duplicar ficha |
| Route Handler | Manejador de ruta HTTP propio del cliente (p. ej. `app/api/**`, `routes/api/**`) |
| BFF | Backend-for-Frontend; capa intermedia propia del cliente |

Términos de **negocio** del proyecto (los que pueden aparecer en el código según R-22): [glosario-dominio.md](glosario-dominio.md). Este glosario es del pack (congelado); aquel lo completa el proyecto.
