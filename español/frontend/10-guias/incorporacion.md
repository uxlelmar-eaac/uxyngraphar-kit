# Incorporación (cliente)

1. Leer `docs/PROTOCOLO.md` y `AGENTES.md`.
2. Configurar variables de entorno del cliente según la config central del proyecto.
3. Instalar dependencias; arrancar la aplicación.
4. Para un dominio: `docs/25-areas/<area>/CONTEXTO.md` antes de explorar a ciegas.
5. Contratos: regenerar tipos desde OpenAPI del servidor cuando el API cambie (si el proyecto lo usa).
