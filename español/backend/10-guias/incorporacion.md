# Incorporación (servidor)

1. Leer `docs/PROTOCOLO.md` y `AGENTES.md`.
2. Configurar variables de entorno según la guía del proyecto (no commitear secretos).
3. Instalar dependencias y arrancar el servicio según el README del repo.
4. Ejecutar migraciones o seeds si el proyecto los usa.
5. Verificar que el API responde y que la documentación OpenAPI/Swagger está accesible (si aplica).
6. Para un dominio concreto: leer `docs/25-areas/<area>/CONTEXTO.md` antes de explorar a ciegas.
