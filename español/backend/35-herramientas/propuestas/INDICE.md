# Propuestas IA — índice
<!-- uxyngraphar:inicio -->

Sugerencias de herramientas pendientes de decisión humana. **No ejecutar.** Organización por estado y fecha (R-17):

```
35-herramientas/propuestas/
├── 01-pendientes/YYYY-MM-DD/   ← pending
├── 02-en-progreso/             ← en-evaluacion
├── 03-completadas/             ← (promovida → sale a autorizadas/)
├── 04-archivadas/              ← archivada
├── 05-canceladas/YYYY-MM-DD/   ← rejected
└── 06-listas-para-eliminar/    ← para-eliminar
```

El árbol es el índice; vista viva: `python3 docs/scripts/decisiones/decisiones.py scan`.

(En Windows: `py -3` en lugar de `python3`.)
