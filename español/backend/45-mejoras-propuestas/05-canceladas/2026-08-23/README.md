# Estado — 05-canceladas

Documentos rechazados o cancelados. Conservar la carpeta de fecha original.

Cada documento vive en una carpeta de fecha de creación (`YYYY-MM-DD`).

Para cambiar de estado, mover el archivo a la carpeta de estado correspondiente **conservando su carpeta de fecha**.

Reglas: guía "Organización por estados y fechas" (`10-guias/organizacion-estados-fechas.md`).
