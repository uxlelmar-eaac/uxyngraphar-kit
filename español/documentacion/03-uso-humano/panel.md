# Panel local

```bash
uxyngraphar panel
```

Abre una UI **solo en tu máquina** (no es la web pública de uxyngraphar.com).

## Suele permitir

- Ver proyectos registrados y su salud
- Instalar / actualizar
- Editar configuración con vista previa
- Plantilla de config para proyectos nuevos
- Decidir colaborar Sí/No

## Elegir carpetas

Cada botón **Examinar…** (Mis proyectos → «Añadir un proyecto que ya tiene uxyngraphar», el asistente de instalación y el de actualización) abre un explorador de carpetas dentro de la página, sin ventanas del sistema. Muestra la ruta actual (cada parte se puede pulsar), un cuadro para escribir una ruta e ir directo, atajos (carpeta personal, Escritorio, Documentos, proyectos registrados y unidades en Windows) y las subcarpetas con las etiquetas «git» y «uxyngraphar». «Usar esta carpeta» la pone en el cuadro; «Cancelar» o `Esc` cierra sin cambiar nada. Solo lee nombres de carpetas de tu equipo: no abre ni modifica archivos.
