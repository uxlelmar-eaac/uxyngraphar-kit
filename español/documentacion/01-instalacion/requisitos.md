# Requisitos

## Obligatorios

- **Python 3.10+** (`python3 --version` o en Windows `py -3 --version`)
- **git** (para sembrar el pack en un proyecto)
- Red HTTPS si instalas desde releases de GitHub

## Recomendados

- Editor con vista Markdown
- CI (GitHub Actions u otro) para `controlar.py`
- Cuenta/org en GitHub si publicas el repo

## Sistemas

Linux, macOS y Windows. Los ejecutables del kit son **solo Python** (stdlib): no necesitas bash/PowerShell propios del kit.

## No requiere

- `sudo` / administrador para la herramienta de usuario
- Node.js para usar el kit documental (sí lo necesitarás si tu *proyecto* es el frontend/backend de la app)
