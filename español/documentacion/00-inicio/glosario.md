# Glosario

| Término | Significado |
|---------|-------------|
| **Pack** | Conjunto documental autosuficiente (servidor o cliente) que se instala como `docs/`. |
| **Núcleo (N)** | Archivos del pack que se actualizan con la herramienta; no los edita la IA a mano. |
| **Plantilla P** | Archivo “rellenar una vez” (p. ej. `configuracion-proyecto.md`). |
| **Contenido C** | Tu trabajo en el proyecto; el instalador **no** lo sobrescribe. |
| **Instrucción** | Contrato de tarea en `05-instrucciones/` con estados (awaiting_approval → approved…). |
| **Anclas** | Rutas de código/docs que la instrucción autoriza tocar. |
| **EVO** | Ficha en `46-evolucion-documentacion/` sobre el propio sistema documental. |
| **Lock** | `docs/.uxyngraphar.lock` — versión del pack en ese proyecto. |
| **Panel** | UI local en el navegador (`uxyngraphar panel`), solo en tu equipo. |
| **Feedback / colaborar** | Opt-in para enviar fichas EVO al mantenedor. |
