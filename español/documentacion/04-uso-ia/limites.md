# Límites y prohibiciones (IA)

## Típico en proyecto con pack

- Máximo de documentos y archivos de código por instrucción (p. ej. 8 docs / 5 código — confirma en PROTOCOLO del pack).
- Tope de líneas por archivo editado.
- Solo rutas en `anclas_codigo` / anclas documentales.

## Prohibido

| Acción | Por qué |
|--------|---------|
| Editar núcleo instalado a mano | Rompe actualizaciones (R-20) |
| Crear carpetas numeradas nuevas del pack | R-14 |
| Activar feedback EVO | Solo humano |
| Leer 95-memoria | R-24 |
| Inventar features del kit en la web/docs | Mantén fidelidad al README/manual |

## Este manual (`documentacion/`)

Sí puedes crear/actualizar páginas del manual cuando el humano lo pida: **no** forma parte del núcleo instalable.
