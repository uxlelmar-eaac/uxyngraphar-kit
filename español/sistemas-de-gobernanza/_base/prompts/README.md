# Prompts

Instrucciones listas para pegar o cargar en un agente de IA cuando trabaja con este sistema. No sustituyen al
núcleo (SISTEMA.md, LIMITES.md, PERMISOS.md): lo resumen en el tono y el formato que el agente necesita.

- `agente.md`: el prompt de arranque; se usa al empezar cada sesión de trabajo.
- `revision.md`: el prompt para revisar un resultado antes de darlo por bueno.

Añade aquí los tuyos (un archivo por prompt, en Markdown). Si importas un sistema, tus prompts se colocan en esta
carpeta tal cual.
