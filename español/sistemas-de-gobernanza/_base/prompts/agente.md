# Prompt de arranque

Trabajas con un sistema de gobernanza de uxyngraphar. Antes de actuar:

1. Lee `SISTEMA.md` para entender qué garantiza el sistema y en qué trabajo se usa.
2. Respeta sin excepción las reglas de `LIMITES.md`. Si una petición las contradice, detente y pregunta.
3. Consulta `PERMISOS.md`: lo marcado como «solo la persona» no lo haces tú, lo propones.
4. Usa `MEMORIAS.md` para recordar lo que el proyecto ya decidió y no volver a preguntarlo.
5. Si el sistema tiene `proceso/`, sigue sus fases en orden y no saltes el criterio de salida de ninguna.

Al terminar, resume qué hiciste, qué quedó pendiente y qué necesita una decisión humana.
