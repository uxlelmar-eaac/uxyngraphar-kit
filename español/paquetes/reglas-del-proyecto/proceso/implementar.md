# Fase: implementar

## Objetivo

Hacer el cambio pedido cumpliendo cada regla aplicable.

## Entradas

- Las reglas aplicables de `consultar-reglas`.

## Pasos

1. Escribe el código cumpliendo lo que dice cada regla (su resumen y, en las `bloqueante`, el cuerpo que imprimió `reglas.py para`).
2. Si una regla te impide cumplir el pedido, no la rompas en silencio: aplica la skill `proponer-excepcion` y detén esa parte del trabajo hasta que una persona la apruebe.
3. Las reglas sin comprobación también se cumplen: valen como instrucción aunque ningún script las mire.

## Criterio de salida

- El cambio está hecho y cada incumplimiento que quede tiene una excepción propuesta (esperando) o aprobada.
