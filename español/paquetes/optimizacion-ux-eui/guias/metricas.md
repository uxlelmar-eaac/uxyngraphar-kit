# Métricas antes/después

Elige métricas que respondan a las tareas del usuario de la evaluación. Mide «Antes» con el mismo método que usarás para «Después».

| Métrica | Buen umbral | Fuente típica |
|---------|-------------|---------------|
| LCP (pintado del contenido principal) | ≤ 2.5 s | Lighthouse, datos de campo |
| INP (respuesta a la interacción) | ≤ 200 ms | Datos de campo, Lighthouse (aprox.) |
| CLS (estabilidad visual) | ≤ 0.1 | Lighthouse |
| Puntuación de accesibilidad | ≥ 95 | Lighthouse/axe |
| Pasos para completar la tarea | menos que antes | Conteo manual del flujo |
| Tasa de éxito de la tarea | ↑ | Prueba con usuarios, analítica |
| Tiempo en la tarea | ↓ | Prueba con usuarios |
| Errores por tarea | ↓ | Prueba con usuarios, registros |

Anota la fuente concreta (herramienta, dispositivo, red simulada, muestra) para que la medición se pueda repetir.
